commitCanvasV2

Draw on a mock GitHub contribution graph, then generate a repository to paint the design onto your real GitHub profile.

🔒
Runs 100% locally on your device: Nothing is sent anywhere. All commits are generated directly in your browser without contacting any external servers. Your GitHub details don't go anywhere and you manually upload the repository to GitHub yourself.
How to use
  1. Draw your design: Click or drag on the graph to draw. Choose a shade using the color swatches (darker green represents more commits on that day; × erases).
  2. Enter your details: Provide the name and email address associated with your GitHub account so GitHub attributes the commits to your profile. (This stays on your device and is only written into your local git commit records.)
  3. Generate repository: Click “Generate repository” to download a zip archive containing the generated Git history.
  4. Manually push to GitHub: Unzip the download and run the terminal commands shown below to upload the commits to your GitHub account.

Push to GitHub (step by step)
  1. Create a new empty repository on GitHub (leave “Add a README file” unchecked, and do not add a .gitignore or license).

commitCanvasV2

Draw on a mock GitHub contribution graph, then generate a repo that paints it onto your real one.

More details
  • Click or drag on the graph to draw. The swatches pick the shade: darker means more commits that day, and × erases.
  • Use the name and email of your GitHub account. The email must be one on your account, or the commits won't count.
  • Generate downloads a zip of a git repository with one commit per brush stroke, dated for the chosen year. Steps to push it appear below once it's downloaded.

Push it to GitHub, step by step
  1. Create a new empty repository on GitHub (no README or .gitignore).
  2. Unzip the download. The .git folder is hidden: on a Mac press Cmd+Shift+. in Finder to see it.
  3. Open a terminal in the unzipped folder and run these, using your repository's URL:

        
The art appears on your profile once the push finishes (it can take a few minutes). It only counts if the repo is public, or if you've turned on private contributions in your GitHub profile settings.
